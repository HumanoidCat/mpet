💬 Spike — ¿Un modelo de chat real reemplaza a LaMini?

Después del arreglo de I-09/I-10/eco, el tutor dejó de romperse pero sigue sin conversar de verdad: no responde preguntas ni recuerda nada de turnos anteriores, porque LaMini-Flan-T5 es un T5 de instrucciones, no un modelo de chat. Este spike mide si un modelo de chat real —con historial y plantilla de chat nativa de @huggingface/transformers— resuelve el problema de fondo en vez de parchearlo.

La prueba que decide: ¿el modelo recuerda un dato dado dos turnos antes? Es algo que LaMini no podía hacer estructuralmente (el prompt solo lleva la última frase) y que un modelo de chat con historial real sí debería poder.
